# おはなしの森の図書館

ミニストーリー（十一〜）を1か所にまとめ、教室の大画面で音読のいろいろなやり方を見せるための、先生用のページです。

- 公開先（GitHub Pages）：https://rubiziumu37-glitch.github.io/ohanashi-mori/
- 仕様：ai-staff-room の `outputs/engineer/20261103-1809_ミニストーリー音読アプリ仕様.md`

## いまできること（段階①）

- 本だな：物語を番号順に並べる。札（学習に用いる言葉）を押すと、その札の物語だけになる
- 本文：白地に文字だけ。縦書き／横書き、文字の大きさ（「ぴったり」で画面に合わせる）、分かち書きの空白のあり・なし
- しるし：登場人物（赤）・会話文（青）・時間（オレンジ）・場所（黒）・オノマトペ（紫）・心情（緑）を、ボタンで1つずつ切り替え
- 読む行だけ：読む行以外を薄くする。矢印キーか、行を押して動かす

## キー

| キー | はたらき |
|---|---|
| Esc | 本だなにもどる |
| H | 下のボタンをかくす・出す |
| S | 読む行だけ |
| ← → （縦書き）／ ↑ ↓（横書き） | 読む行を動かす |
| ＋ − 0 | 文字を大きく・小さく・画面に合わせる |

## 物語を足すとき

ふだんは、本文をチャットで送れば AI が `data/stories.json` に足します。書き方は `CLAUDE.md`。
